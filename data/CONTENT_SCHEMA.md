# Content editing quick reference

- Edit `site.json` for your name, hero copy, nav, education, and contact URLs.
- Edit `projects.json` to add or update projects. Every `slug` becomes `/projects/[slug]`. Supports `coverImage` (single cover image), `previewImages` (list of images for the interactive slider in project detail), and optional `links.demo` & `links.repository` (only rendered when filled).
- Edit `experience.json` for agency/work timeline entries.
- Edit `skills.json` for technology groups.

Use valid JSON only: double quotes, no comments, no trailing commas. Empty URLs should remain empty until a real URL is available. Confirm every project feature before publishing it.
