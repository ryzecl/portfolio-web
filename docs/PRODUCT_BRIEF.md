# Product Brief

## Product
A personal portfolio for Ferry Noer Hendriawan, an Information Systems student and hands-on developer who has worked on client and academic/personal software projects.

## Primary goals
1. Make the owner's identity and development focus clear within a few seconds.
2. Showcase real work with enough context to demonstrate technical contribution.
3. Support internship applications, especially full-stack/backend/Laravel-related roles, without pretending the owner is a senior engineer.
4. Make adding and updating projects easy through JSON files.
5. Present a distinctive visual identity that feels professional and memorable.

## Audiences
- Internship recruiters and engineering teams.
- Potential freelance clients.
- Developers and collaborators reviewing the owner's work.

## Positioning
"Building practical digital solutions by connecting software, systems, and real-world needs."

The tone should be direct, human, quietly confident, and specific. Avoid inflated claims and generic phrases.

## Main user journeys
### Recruiter
Landing page → featured projects → project case study → skills/experience → CV/contact.

### Potential client
Landing page → relevant client project → features and contribution → contact.

### Developer
Projects listing → technologies and implementation details → repository/demo if the owner has supplied a public URL.

## Information architecture
- Home: concise hero, selected projects, short about preview, tech stack preview, contact CTA.
- Projects: full project index with clear status, category, stack, and project links.
- Project detail: problem/context, solution, features, role, implementation, challenges, gallery, links.
- About: short biography, education, experience, and skill categories.
- Contact: actual supplied contact links, with unavailable links omitted rather than fabricated.

## Success criteria
- The visitor can identify the owner, role, and main work quickly.
- Projects are more prominent than decorative effects.
- Layout is readable and responsive at narrow mobile widths.
- Project content is maintained in JSON.
- No fabricated facts, fake statistics, broken links, or dead navigation.
